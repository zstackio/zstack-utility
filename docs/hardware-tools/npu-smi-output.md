# Huawei NPU `npu-smi` 输出记录

本文档只记录不同硬件型号、不同场景下执行 `npu-smi` 命令得到的真实输出，供代码解析、测试和问题排查参考。

记录 ID 格式：`$硬件型号_$场景_$npu-smi简称_output`

- 硬件型号使用小写，例如 `910c`、`910b`
- 场景使用简短英文，例如 `normal`、`warning`
- 原始输出保持采集格式，不修改字段内容
